DiscordSRV

WIKI LAST REVIEWED: AUGUST 5, 2026Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.
COMMUNICATION & DISCORD

DiscordSRV bridges supported Minecraft and Discord communication and provides optional account-linking and synchronization tools.

PLAYER FEATURES Minecraft and Discord Connection

DiscordSRV connects supported Minecraft communication and server activity with the Pinnacle Discord. Depending on current server settings, it can relay chat, identify linked accounts, and synchronize selected Discord or Minecraft information.

Common Player Commands

Command availability depends on the permissions and features currently enabled on Pinnacle SMP.

CommandWhat it does
/discordShows the server's Discord information or the main DiscordSRV menu.
/discordsrvAlias of /discord.
/discord helpShows the DiscordSRV options available to you.
/discord linkProvides instructions and a verification code for linking your Minecraft and Discord accounts.
/discord linkedShows whether your Minecraft account is linked to Discord.
/discord unlinkUnlinks your own account when that option is permitted.

Linking an Account

  1. Run /discord link in Minecraft.
  2. Follow the instructions shown by the server.
  3. Send the generated verification code to the specified Discord bot or channel.
  4. Wait for confirmation that the Minecraft and Discord accounts are linked.

What Linking May Affect

  • Identifying which Discord member belongs to a Minecraft account.
  • Access to linked-account features or Discord roles.
  • Nickname or group synchronization when enabled by the server.
  • Requirements for joining or using selected Discord-connected features.

ADMIN ONLY DiscordSRV Staff Commands

CommandWhat it does
/discord broadcast <channel> <message>Broadcasts a message to a configured Discord channel.
/discord linked <player|uuid|discord account>Checks another account's link status.
/discord link <player|uuid> <discord account>Links another Minecraft and Discord account.
/discord unlink <player|uuid|discord account>Unlinks another account.
/discord resyncForces configured group and role synchronization.
/discord reloadReloads DiscordSRV. Some changes may still require a restart.
/discord debugger <start|stop|upload>Runs DiscordSRV diagnostic tools.
/discord language <language>Changes the plugin language when permitted.

Important Notes

Never post your linking code publicly unless the server's instructions specifically direct you to a protected linking channel. Treat it as a temporary verification credential.
DiscordSRV has many optional features. A command listed here may be unavailable when Pinnacle SMP has not enabled that feature or has limited its permission.
Messages sent between Minecraft and Discord remain subject to both the Minecraft server rules and the Discord community rules.
