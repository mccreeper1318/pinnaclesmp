Last Seen to Discord

WIKI LAST REVIEWED: AUGUST 5, 2026Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.
COMMUNITY & DISCORD

Last Seen to Discord keeps a Discord message updated with the recent activity status of server members.

AUTOMATIC COMMUNITY FEATURE Discord Activity List

Last Seen to Discord maintains the server activity list posted in Discord. It identifies members as active or inactive using recent server activity.

How It Works for Players

  • Players active within the current activity window appear as active.
  • Players who have not been seen within that window appear as inactive.
  • Online players are treated as active.
  • The Discord list is refreshed automatically, including after joins and quits.

Player Commands

There are no normal player commands. Joining, leaving, and ordinary server activity update the information automatically.

ADMIN ONLY Activity Sync Commands

CommandWhat it does
/lastseendiscord syncQueues an immediate Discord activity-list update.
/lastseendiscord reloadReloads the plugin and queues a fresh Discord update.
/lsd syncShort alias for the manual sync command.
/lsd reloadShort alias for the reload command.

Important Notes

The current activity threshold is 30 days. This can change, and the Discord post may take a short time to refresh after activity.
The activity list only shows server recency. It does not measure how much someone contributed, why they were away, or whether they remain part of the community.
