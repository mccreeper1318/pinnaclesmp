PLUGIN GUIDE

Deaths to Discord

Player-facing guidance for the plugins used on Pinnacle SMP.

WIKI LAST REVIEWED: SEPTEMBER 1, 2026Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.
STATISTICS & DISCORD

Deaths to Discord keeps a ranked Discord death leaderboard synchronized with the Minecraft death scoreboard.

AUTOMATIC COMMUNITY FEATURE Discord Death Leaderboard

Deaths to Discord reads the server's death scoreboard and maintains a ranked leaderboard message in Discord. The leaderboard updates after player deaths.

How the Leaderboard Works

  • Players are sorted from the highest death count to the lowest.
  • Ties are sorted by player name.
  • Offline players can remain on the leaderboard.
  • The current server mode lists everyone and includes players with zero recorded deaths.
  • A short delay can combine rapid deaths into one Discord update.
  • If the full list exceeds Discord's message limit, the plugin includes as many ranked players as fit and reports how many were omitted.

Player Commands

There are no normal player commands. The death score and Discord message update automatically.

Where the Number Comes From

The plugin uses the server's Minecraft scoreboard objective for deaths. It displays that recorded score; it does not independently decide whether an event should count as a death.

ADMIN ONLY Death Leaderboard Command

CommandWhat it does
/d2d reloadReloads Deaths to Discord and immediately updates the Discord leaderboard message.

Important Notes

The leaderboard is for community information and fun. A high or low death count is not a measure of skill, contribution, or rank.
Temporary Discord timeouts, rate limits, and server errors retry automatically. If the managed leaderboard message is deleted, the plugin creates a replacement during the next update.
If the configured Minecraft scoreboard objective is missing or invalid, the leaderboard cannot update until staff correct it.
