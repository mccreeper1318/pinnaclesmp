Frequently Asked Questions

What is Vanilla+?
Pinnacle runs Paper and uses plugins, but the goal is to preserve the core vanilla Minecraft experience rather than becoming heavily modded or overloaded with systems.
What does whitelisted mean?
Only approved players on the server whitelist can connect. Pinnacle normally uses an application process for adults age 18 and older, although applications are currently closed.
How old is the current world?
Season 12 began in April 2026. There is no fixed reset schedule and no current reset planned. A reset requires at least 90% agreement in a vote of server members.
Where is the server hosted?
The server is hosted in the eastern United States and is intended to remain available 24/7.
Is there a live world map?
Yes. Use the live map or the direct map link listed on the Links page.
What happens when applications reopen?
Applicants read the rules, answer the application questions, and may receive a short Discord interview. Staff normally tries to respond within about 24 hours, although real-life schedules can cause delays.
My application was accepted. How do I connect?
Check the #server-info channel in the Pinnacle Discord for the current connection information and staff instructions.
Which client mods are allowed?
The public FAQ states that only performance-enhancing mods are allowed. Ask an Admin or Founding Member before using any tool that might provide an advantage.
How quickly does Pinnacle update Minecraft?
Updates are normally installed after the appropriate server software is available from the host and required plugins are compatible. Discord and in-game announcements are used when an update is approaching.
Can I suggest an event or plugin?
Yes. Contact an Admin or Founding Member for event ideas, or use the official Plugin Suggestions form on the Links page.
Can a banned player appeal?
Yes. The official Ban Appeal form is linked from the Join / Contact and Links pages.
How are membership promotions decided?
There is no fixed promotion timer. Rank changes are based on overall involvement, contributions, conduct, and becoming part of the community.
