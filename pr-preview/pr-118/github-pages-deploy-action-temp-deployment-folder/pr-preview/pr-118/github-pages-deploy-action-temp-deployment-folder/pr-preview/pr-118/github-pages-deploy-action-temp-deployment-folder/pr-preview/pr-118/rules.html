Server Rules

Review these rules before joining or participating in Pinnacle SMP community spaces.

  1. Community Standards
    18+ Only
    Pinnacle SMP is an 18+ server. Applicants and players must be at least 18 years old.
  2. Gameplay Rules
    No Cheating
    No x-ray, duplication, exploits, hacked clients, or unfair mods. Ask staff when unsure about a client-side tool.
  3. Gameplay Rules
    No Griefing
    No stealing, lava casting, unwanted destruction, or modifying another player’s property without permission.
  4. Gameplay Rules
    PvP Requires Consent
    No random PvP, traps, or harmful item use against players who have not agreed to participate.
  5. Community Standards
    Respect Others
    No harassment, hate speech, personal attacks, or conduct intended to make other members feel unsafe or unwelcome.
  6. Community Standards
    Chat Rules
    No spam, advertising, or public non-English chat. Keep public communication readable and appropriate for the community.
  7. Server Etiquette
    Limit Lag
    Keep farms, redstone, entities, and machinery efficient. Follow staff directions when a build harms server performance.
  8. Server Etiquette
    No Chunk Loaders
    Do not keep chunks loaded while away from the area or server.
  9. Server Etiquette
    No Gambling or Scamming
    No casinos, paid mystery boxes, dishonest trades, or attempts to deceive other players.
  10. Server Etiquette
    Report Issues
    Report problems to staff rather than mini-moderating, escalating arguments, or publicly confronting players.
  11. Gameplay Rules
    No Alt Accounts
    Do not use alternate accounts or attempt to bypass restrictions, punishments, or membership decisions.
  12. Server Etiquette
    No Illegal Activity
    Do not use the server or its community spaces for illegal content or activity.
Staff may use discretion when handling situations that are not directly covered. When in doubt, ask an Admin or Founding Member before acting.
