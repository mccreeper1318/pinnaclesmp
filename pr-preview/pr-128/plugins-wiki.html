PLAYER GUIDES

Plugins Wiki

Player-facing guides for the plugins used on Pinnacle SMP.

WIKI LAST REVIEWED: AUGUST 5, 2026 Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.

This wiki explains the plugins currently used by Pinnacle SMP from a player-facing perspective. Each guide covers what the plugin does, how players interact with it, available commands, practical examples, and important limitations. Staff-only commands and abilities are included where useful and are clearly marked ADMIN ONLY.

PLUGIN TYPE describes the plugin's main purpose. ADMIN ONLY means ordinary players cannot use that command or feature.

Square Map

MAP & NAVIGATION

A browser-based live map for exploring the world, checking terrain, and finding shared locations.

OPEN SQUARE MAP GUIDE

PinnacleStats (PStats)

STATISTICS & WEBSITE

Collects Minecraft statistics and publishes them to Pinnacle SMP member profiles.

OPEN PINNACLESTATS (PSTATS) GUIDE

Pinnacle AFK

UTILITY

Lets players mark themselves AFK, freezes movement, and adds delayed damage protection.

OPEN PINNACLE AFK GUIDE

Last Seen to Discord

COMMUNITY & DISCORD

Keeps the Discord activity list updated with active and inactive server members.

OPEN LAST SEEN TO DISCORD GUIDE

FragStealers

SECURITY, SHOPS, MAIL & TRUST

Current server version: 26.2-6 Beta 2. Protects storage, runs shops and mailboxes, and lets owners grant access-level or manage-level trust.

OPEN FRAGSTEALERS GUIDE

FragGuard

SECURITY & RECOVERY

Records block changes so staff can investigate griefing and roll damaged areas back.

OPEN FRAGGUARD GUIDE

DiscordSRV

COMMUNICATION & DISCORD

Connects Minecraft and Discord chat and supports account-linking features.

OPEN DISCORDSRV GUIDE

Deaths to Discord

STATISTICS & DISCORD

Maintains the server death leaderboard in Discord and updates it after deaths.

OPEN DEATHS TO DISCORD GUIDE
