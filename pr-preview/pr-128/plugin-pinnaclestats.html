PLUGIN GUIDE

PinnacleStats (PStats)

Player-facing guidance for the plugins used on Pinnacle SMP.

WIKI LAST REVIEWED: AUGUST 5, 2026Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.
STATISTICS & WEBSITE

PinnacleStats turns Minecraft player statistics into formatted data used by the Pinnacle SMP website.

AUTOMATIC PLAYER FEATURE Website Statistics

PinnacleStats reads Minecraft statistics and publishes formatted results for Pinnacle SMP member profiles. Players do not need to enable it or run a command for normal tracking.

What It Is Used For

  • Displaying player statistics on member profile pages.
  • Keeping website statistics connected to the current Minecraft world data.
  • Providing staff with a consistent way to refresh and publish profile statistics.

Player Commands

There are no normal player commands. Statistics are collected and published automatically.

When Statistics Update

The website may not change immediately after an in-game action. PinnacleStats uses cached data and published website files, so profile numbers can be behind the live server until the next refresh and publish.

ADMIN ONLY PinnacleStats Commands

CommandWhat it does
/pstats statusShows whether the statistics service is running, how many players are loaded, and the latest refresh/export status.
/pstats reloadReloads PinnacleStats and restarts its statistics service.
/pstats refreshRefreshes all cached player statistics.
/pstats refresh <player>Refreshes one player's cached statistics.
/pstats exportCreates a local website statistics export without publishing it.
/pstats publishExports and publishes the current website statistics.
/pstats debug <player|uuid>Shows the cached record and output locations for a player.

Important Notes

The profile page is the player-facing result of this plugin. A delayed or missing statistic does not necessarily mean the underlying Minecraft statistic was lost.
Statistics depend on the data Minecraft records. They are informational and should not be treated as a complete measurement of a member's activity or contribution.
