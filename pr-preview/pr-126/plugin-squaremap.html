Square Map

WIKI LAST REVIEWED: AUGUST 5, 2026Plugin features, commands, and server permissions may change after updates. This guide may not always reflect the newest server version immediately.
MAP & NAVIGATION

Square Map provides Pinnacle SMP's live browser map and tools for viewing or managing rendered world information.

PLAYER FEATURE Live World Map

Square Map creates the browser-based map used by Pinnacle SMP. It lets players view rendered terrain, switch between available worlds, zoom in and out, read coordinates, and find visible player or server markers.

OPEN LIVE WORLD MAP

What Players Should Know

  • The map is a rendered view of the world, not a replacement for exploring in Minecraft.
  • New construction or terrain changes may take time to appear.
  • A player may not appear when player markers are hidden or unavailable.
  • Blank areas generally have not been rendered or made available on the map.
  • The coordinates shown by the map can help with roads, events, meeting points, and shared builds.

Player Commands

These commands are available only when the server grants the related Square Map permission.

CommandWhat it does
/map help [query]Opens the interactive Square Map command help.
/map linkPrints the configured map link. When supported, the link can follow your current player marker.
/map hideHides your own player marker from the map.
/map showMakes your own player marker visible again.

ADMIN ONLY Map Management Commands

CommandWhat it does
/map fullrender [world]Starts a full render for the selected world.
/map radiusrender <world> <radius> [center]Renders the selected radius around a location.
/map cancelrender [world]Stops an active render.
/map pauserender [world]Pauses or resumes a render.
/map reloadReloads Square Map.
/map resetmap <world>Deletes the rendered tiles for a world. This requires confirmation and cannot be undone.
/map confirmConfirms a pending destructive command such as resetting a map.
/map hide [player] / /map show [player]Changes another player's map visibility.
/map progresslogging [toggle|rate <seconds>]Views or changes render progress reporting.

Important Notes

Privacy: The web map should not be treated as a guarantee that another player is online, visible, or at the exact location shown.
Map differences: A recently changed area can look outdated until its map tile is rendered again.
