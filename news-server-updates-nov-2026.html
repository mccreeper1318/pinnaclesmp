UPDATE

Server Updates

Plugin updates bring stronger rollback tools, improved stability, new mob head trophies, better mapping, and clearer server changelogs.

UPDATENOVEMBER 9, 2026

Several Pinnacle SMP plugins have received updates, bringing new features, performance improvements, and reliability fixes. We have also added ServerChangelogs to help players stay informed about changes.

Updated FG to 26.3-1.2.1

What's New

  • Player-specific Rollbacks: Look up and reverse changes made by a particular player across multiple worlds.
  • Better TNT and Redstone Tracking: Improved attribution of explosions, piston movement, and supported redstone mechanisms.
  • Safer Rollbacks: Better protects changes made by other players or the environment.
  • Faster History Searches: Improved performance when searching large amounts of block history.
  • Database Improvements: Reduced migration storage requirements and improved recovery from interrupted upgrades.
  • Bug Fixes: Various fixes to improve stability and reliability.

D2D Updated to 1.5.1

What's New

  • Updated for Paper 26.3 Stable Build 244.
  • Updated internal dependencies for improved compatibility and maintenance.

LSD Updated to 1.2.1

What's New

  • Added /lsd status for checking synchronization status.
  • Added a safe webhook connection test.
  • Added a guarded message-state reset command.
  • Added separate command permissions and tab completion.
  • Added optional page numbers, repeated headings, and player activity summaries.
  • Added configurable activity timezone and date formatting.
  • Added optional Discord-native timestamps.
  • Disabled Discord mentions in webhook messages to prevent accidental pings.
  • Updated to Paper 26.3 Build 244 Stable.
  • Updated several internal dependencies and build tools.

pStats Updated to 1.1.1

What's New

  • Cleaner exports: Old player files are handled more safely when players are renamed or removed.
  • More reliable API: Improved connection handling helps prevent stalled or excessive requests from tying up the API.
  • Safer data processing: Malformed, oversized, or unusually complex JSON data is rejected before it can cause problems.
  • Better background stability: API workers, shutdowns, and reloads are handled more cleanly.

pHeads Updated to 0.1.1

What's New

  • Prize Heads: Supported mobs can now drop special ultra-rare trophy versions of their heads with unique names, lore, glint, metadata, and optional particle effects.
  • Trophy Command: Admins can use /ph give trophy <mob-head> to give themselves a Prize Head.
  • More Paper 26.3 mobs: Added Creaking, Happy Ghast, Copper Golem, Nautilus, Zombie Nautilus, Camel Husk, Parched, and Sulfer Cube heads.
  • More accurate mob heads: Cows, pigs, and chickens can now drop heads matching their cold, temperate, or warm appearance.
  • Copper Golem variants: Natural drops can match unaffected, exposed, weathered, and oxidized Copper Golems.
  • Zombie Nautilus variants: Natural drops can match temperate and warm Zombie Nautiluses.
  • Better texture sourcing: Newer custom heads use pinned and documented texture sources instead of guessed or generated textures.

Added ServerChangelogs Plugin

  • Added the ServerChangelogs plugin to better convey changes made with the plugins to joining players.

Updated SquareMap to 1.4.3

What's New

  • Performance: Significantly faster map rendering and reduced server resource usage.
  • Visual: Improved biome colors, vegetation, terrain shading, and overall map accuracy.
  • Bug Fixes: Fixed missing chunks, rendering interruptions, and map reset issues.
  • Reliability: Improved background rendering, chunk processing, and rendering recovery after restarts.
  • Configuration: Reorganized rendering settings with automatic migration.
  • Overall: Faster, more accurate, and more reliable map rendering with better server performance.
